# S Browser

Изолированный браузер на Chromium (Electron). В интернет выходит **только через ваш прокси**.

## Скачать готовый установщик

Установщик собирается автоматически через GitHub Actions:
- **Releases** (справа на главной странице репозитория) — стабильные версии `SBrowser-Setup-X.Y.Z.exe`;
- **Actions → последняя сборка → Artifacts** — сборка после каждого изменения.

## Запуск из исходников

Нужен Node.js 18+ (https://nodejs.org).

```bash
cd Proxy-browser
npm install
npm start
```

При первом запуске откроется окно настроек: укажите тип прокси, адрес и порт. После сохранения браузер перезапустится.

## Сборка в отдельное приложение

```bash
npm run dist
```

Готовый файл появится в папке `dist/`: на Windows это portable `.exe`, на macOS `.dmg`, на Linux `.AppImage`.

## Что обеспечивает изоляцию

| Угроза | Защита |
|---|---|
| Прокси упал, и трафик пошёл напрямую | Прямого подключения нет вообще: без прокси страницы не грузятся |
| Утечка DNS | Локальное разрешение имён запрещено, кроме адреса самого прокси |
| Утечка реального IP через WebRTC | WebRTC работает только через прокси, UDP/QUIC выключены |
| Доступ к локальной сети и localhost | Эти запросы тоже идут через прокси |
| Доступ к файлам компьютера | `file://` заблокирован, загрузки сохраняются только в свою папку |
| Камера, микрофон, геолокация, USB, уведомления | Всё запрещено |
| Cookies и данные других браузеров | Отдельная папка данных, ничего не делится с Chrome, Edge и другими |
| Электрон в User-Agent | Удалён, сайты видят обычный Chrome |
| Чтение кэша, ETag-«суперкуки» | Кэш на диск не пишется (`no-store`), заголовки ETag/Last-Modified вырезаются, при запуске очищаются кэш, CacheStorage и service workers |
| Закладки | Хранятся локально в `bookmarks.json`, сайтам недоступны |
| Часовой пояс системы | Подменяется (по умолчанию Asia/Singapore, UTC+8) для страниц, iframe-ов и воркеров |
| Трекеры через сторонние cookies | Cookies не уходят на чужие домены и не принимаются от них |

В правом верхнем углу показан внешний IP. Зелёный значок означает, что прокси работает, красный — что прокси недоступен и соединение заблокировано.

## Автоперевод

Страницы на другом языке автоматически переводятся на выбранный в настройках язык (по умолчанию русский). Кнопка **文A** (Ctrl+Shift+Y) включает и выключает перевод; если выключить его на сайте, этот сайт больше не переводится автоматически. Текст отправляется в Google Переводчик через прокси.

## Автообновление

Браузер раз в 3 часа (и через 15 секунд после запуска) проверяет новые версии в Releases этого репозитория через прокси и скачивает их в фоне. Когда обновление готово, в панели появляется зелёная кнопка «⬆ Обновить до X» — или оно установится само при закрытии браузера. Для работы автообновления репозиторий должен быть публичным.

## Где хранятся данные

- Windows: `%APPDATA%\SBrowser`
- macOS: `~/Library/Application Support/SBrowser`
- Linux: `~/.config/SBrowser`

`config.json` содержит настройки прокси. Пароль шифруется средствами ОС: DPAPI на Windows, Keychain на macOS, keyring на Linux, если он доступен. Загрузки лежат в подпапке `Downloads`.

## Ограничения

- **SOCKS5 с логином и паролем Chromium не поддерживает.** Используйте HTTP/HTTPS-прокси с авторизацией или SOCKS5 с доступом по IP без пароля.
- Это изоляция на уровне приложения. Шрифты, разрешение экрана, часовой пояс и видеокарта по-прежнему видны сайтам в отпечатке браузера. Для полной изоляции запускайте браузер в виртуальной машине.

## Горячие клавиши

Ctrl+T — новая вкладка, Ctrl+W — закрыть вкладку, Ctrl+L — адресная строка, Ctrl+R / F5 — обновить, Alt+← / Alt+→ — назад / вперёд, Ctrl+D — добавить или убрать закладку, Ctrl+Shift+Y — перевод, кнопка ⤓ — панель загрузок (прогресс, скорость, пауза, отмена), F12 или Ctrl+Shift+I — инструменты разработчика. На macOS вместо Ctrl используется Cmd.
